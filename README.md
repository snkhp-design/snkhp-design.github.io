# Anna Sankhip — portfolio

Personal portfolio site. Static HTML, no build step, no dependencies.

## Structure

```
index.html                 the whole site: markup, styles, scripts
assets/                    images and the downloadable CV
```

## Running it locally

Open `index.html` in a browser. Nothing to install.

## Editing

Case study text and card positions live in `index.html`, in the
`CARDS` array and the `PAGES` object near the top of the script.

Covers are plain JPEGs in `assets/`. To swap one, replace the file
and keep the name.

## Publishing

The site is served by GitHub Pages from the `main` branch.
